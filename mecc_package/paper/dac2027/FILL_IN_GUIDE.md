# 高亮稿填写指南

当前阅读文件：`mecc_dac2027_polished.pdf`。原同名旧 PDF 被阅读器占用时，不强行关闭阅读器；新稿另存。图形的统一生成入口是 `python build_paper_figures.py`，不使用早期绘图函数覆盖当前配图。

- **黄色**：虚拟数值、虚拟结果标识、尚未完成的实验或待冻结信息。正文数值使用 `\draftvalue{...}`，说明使用 `\draftnote{...}`；替换真实结果时，同时更新对应图和证据记录。
- **浅蓝色**：`Content Generated by AI` 标题及说明。核实实际使用范围后修改，不应在填写结果时顺手删除披露。
- 图顶的黄色 `HYPOTHETICAL · NOT MEASURED` 对该整张结果图生效。每根柱子/折线数据都仍是虚拟值，并非只有黄色标签本身需要核实。
- 页脚黄色说明对整份设计稿生效；保留到所有虚拟数据已经替换且核验完毕。

| 填写位置 | 对应数值源/操作 |
|---|---|
| 摘要、主结果 TPOT、TTFT | `ideal_assumptions.json` 的 `tpot_seconds` / `ttft_seconds`；正文、图、加速比一起更新 |
| 三项动机 | `motivation`；补足独占 LRU 和 2×2 对照，不能仅替换已画出的三个系列 |
| 部署表 | `resident_gpu_tpot_seconds` 与单卡 MECC；同步重新计算 GPU-s/token |
| 消融 | `ablation_tpot_seconds` / `ablation_ssd_percent`；另外补独立归因对照 |
| 主存预算曲线 | `cpu_budget_gb` / `budget_tpot_seconds`；每个点先做物理内存审计 |
| 初始化摊销 | `startup_cost_seconds` / `startup_decode_tpot_seconds`；完整请求另需 adapter TTFT、profiling/loading 成本 |
| 质量目标 | `quality`；用实际 hashes、router IDs、logits、tokens、PPL 报告替换，不预设零误差 |
| 实验设置 | 冻结模型、数据集、prompt IDs、软件版本、计时边界与重复方案 |
| AI 说明 | 修改 TeX 末尾 `\ainote{...}`，保留事实准确的使用范围 |

`ideal_assumptions.json` 仍是设计目标档案，不直接改名为真实结果文件。真实运行先落独立 raw JSON，登记 `docs/PROVENANCE.md`，再把图表生成器接到经核验的数据；不要把手填目标升格为 verified。

构建：`pdflatex -jobname=mecc_dac2027_polished -interaction=nonstopmode -halt-on-error mecc_dac2027.tex`，然后 `bibtex mecc_dac2027_polished`，再运行两次相同 pdflatex 命令。检查：`python verify_draft.py --stem mecc_dac2027_polished` 和 `python verify_visual_layout.py`。大图预览：`python build_gallery.py`。
