# R17：仅缩小偏大的图中文字

按最新要求，以 R16 为基底：较小字号保持原样，只缩小在论文中显示后超过正文大小的图中文字。

- 图 1：较大的策略名、坐标刻度、轴标题和面板标题缩至正文大小；原来的数据标签不放大。
- 图 3：两个偏大的阶段标题略微缩小。
- 图 5：初始状态及 HBM/CPU 标题缩小。
- 图 7：较大的策略名和坐标刻度缩小。
- 其余十二张嵌入图的 PDF 字节保持 R16 原样，图 11 配色也保持不变。

总计调整 33 个偏大文本项，正文 9 TeX pt 对应 PDF 中约 8.966 pt。原本更小的文字保留其字号、位置与内容。字号判定以图在论文中的最终宽度为准，不以绘图软件的原始设置为准。

第一页保留左栏摘要和引言、右栏图及贡献的结构。引言第三段补充缓存状态跨 token 和请求复用的说明，调整贡献条目的间距。两栏正文底端相差不到一行，没有补入新的实验数字。

四段引言和三项贡献的对应关系保留。数值、数据身份说明和旧版原稿保持不变。此前放大全部图中文字的未采用试排留在 layout_trials/uniform_font_20261108，本版未使用该试排。

重建：在尚无 R17 目录时运行 `revise_r17_typography.py`，随后在新目录运行 latexmk。最终字号及每个改动项见 FIGURE_FONT_AUDIT.json。
