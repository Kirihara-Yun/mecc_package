## 章节与分析

删除第六页独立 Related Work。最近邻系统放回 Introduction，其余引用随背景中的设计选择及方法中的交付调度展开；44 个引用键均保留。

腾出的篇幅用于以下分析：

- **请求来源与延迟**：比较 MECC/RF 的 HBM、CPU、HDD 需求分布，解释为什么 HBM 命中比例不能单独决定交付成本；区分首 token 与 decode 的排名。
- **消融与关键路径**：把组件增加后的延迟变化拆成节省的秒数；在需求分布相同的最后一步，区分暴露读盘时间与 H2D 时间的变化。
- **模型与容量**：比较相对增益和绝对节省；分析连续主存增量的收益变化，并联系完整专家覆盖。
- **画像迁移**：分别汇总热图的对角线和六个非对角线单元，区分同任务校准与跨任务适应。
- **校准与批处理**：分析样本数的边际变化；将聚合吞吐量换算为同步 batch 的步间隔，区分总吞吐与单序列进度。
- **初始化摊销**：由额外初始化时间和 decode 节省推导交点；说明共享缓存时摊销的单位是缓存生命周期内的输出，而非每个 prompt 各自重新初始化。

新增数值均由已有数组计算。`DERIVED_ANALYSIS.json` 保存计算结果和输入哈希；没有增添真机运行或改变图中数组。相关数值保留黄色高亮，第八页明确说明其来源与数据性质。
