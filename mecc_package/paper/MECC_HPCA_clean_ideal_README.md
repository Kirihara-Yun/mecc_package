# MECC 内部审阅版

论文：[PDF](./dac2027/mecc_dac2027_clean.pdf) / [LaTeX](./dac2027/mecc_dac2027_clean.tex)。当前 PPT：[可编辑 17 页版本](./current/MECC_HPCA_current.pptx) / [PDF](./current/MECC_HPCA_current.pdf)。PPT 由现有 `MECC_HPCA_review_revision.pptx` 派生；第 1 页解释单卡部署问题、应用场景与三项 Insight；第 2 页保留 `MECC_conference_talk.pptx` 的黑白功能对照表。第 3 页用同一三级驻留图展示三项 Insight 如何依次作用于启动、再访和热点变化。第 4–6 页分别讨论冷启动、有限槽位造成的重复冷读、服务过程中的热点漂移；每页左侧为结果图，右侧为因果示意。第 7–9 页逐一回答问题，第 10–12 页解释系统架构与方法，第 13–17 页为理想结果与总结。

本版供作者审阅论文与组会叙事。论文中的性能和资源数据来自 `dac2027/ideal_assumptions.json`，是理想设定；PPT 第 4–6、13–16 页也使用这些设定。第 4 页的首 token 延迟包含预填充和首次专家交付，并非单独的 SSD 读取时间。原版 PPT 中的 D1 合成回放与本版理想数值不是同一次 GPU 实测，不能合并解释。论文来源哈希见 `dac2027/clean_review/SOURCE_NOTE.json`。原始带标记论文、PPT 和原始实验文件均保留。

DAC 2027 [官方投稿要求](https://dac.com/2027/program/research-manuscript-submissions)规定：LLM 生成的文字、图像和代码须在论文的“Content Generated by AI”独立章节披露。正式投稿前还必须用真实实验替换理想设定，恢复合规披露并检查物理预算、公平基线、数值等价和统计口径。此审阅版不作为投稿文件。

重建论文图与 TeX：`cd dac2027 && python build_clean_review.py`，然后运行 `pdflatex`、`bibtex`、`pdflatex` 两次。重建本版 PPT：`python refine_hpca_talk.py`。构建脚本会调用 `build_hpca_clean_talk.py` 中的绘图函数。逐页初学者检查与修改记录见 [PPT_BEGINNER_REVIEW.md](./PPT_BEGINNER_REVIEW.md)。文件角色见 [PRESENTATION_INDEX.md](./PRESENTATION_INDEX.md)。
