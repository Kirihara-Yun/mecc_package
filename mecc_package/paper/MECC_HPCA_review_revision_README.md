# MECC 审稿修订版（2026-10-28）

交付：`MECC_HPCA_review_revision.pptx`、同名 PDF，共 14 页。保留 1013 模板的白底、蓝线和中文解说。三位 AI 协作者分别模拟 HPCA 的体系结构、因果计量、基线有效性审查；并非实际 HPCA 评审，也没有虚构“三票 Accept”。

本版的核心变化是把背景常识变成三个可证伪的问题：初态的独立收益有多少、同频次不同次序为何改变冷读、先验与在线规则在失配后是否互补。

| 页码 | 内容 | 数据身份 |
|---|---|---|
| 1–3 | 问题、相关机制、MECC 因果分解 | 机制示意 / 一手文献事实表 |
| 4 | 相同在线规则下画像/随机初态的启动冷读；实际初始覆盖热图 | 真实执行的 D1 合成序列回放 |
| 5 | 原序/阶段内保频乱序 × 三种保留；实际再访距离 CDF | 真实执行的 D1 合成序列回放 |
| 6 | 初始画像 × 在线规则 2×2；冻结序列的阶段热度图 | 真实执行的 D1 合成序列回放 |
| 7–12 | 三个对应设计决策、总览与方法 | 逻辑机制，不当作新性能结果 |
| 13 | 历史 A100 1.33× | 既有 D2 JSON 的参考观测；X7–X9 未关闭 |
| 14 | 局部工作集/均匀独立请求的机制控制 | D1 合成序列回放，保留弱收益与负对照 |

第 4/5/6/14 页均不再使用手填占位数字。所有计数由 `scripts/motivation_causal_replay.py` 实际计算：N=16、H=2、C=4、8 个配对种子、无预算外镜像和预取。画像来自相同生成机制的独立训练 RNG；测试 trace 全部保存。阶段内 shuffle 逐对象计数完全相同。图上误差棒是合成种子标准差，不是 GPU 重复运行方差；CDF/热图固定取种子列表首项 3，不按结果选图。

联合臂在这个等大小排他模型中与普通全局 LRU 的需求未命中逐请求一致；不声称新替换算法。固定/独立/联合臂的比较同时包含动态保留与跨层重复覆盖变化，唯一驻留数和迁移对象数单独记录。不能把 miss 差异换算成 A100 速度。

图表：`hpca_revision_assets/` 内同时有 PNG 和矢量 PDF；原值：`results/raw/motivation_causal_replay_20261027_v2.json`。v1 保留，图表不混用。实验协议与三视角意见分别在 `docs/HPCA_CAUSAL_REPLAY_PROTOCOL.md`、`docs/HPCA_REVIEW_AND_REVISION.md`。

复现：先运行 `python mecc_package/scripts/motivation_causal_replay.py`，再运行 `python mecc_package/paper/build_mecc_hpca_revision.py`。`verify_claims.py` 会检查 D1 原值、统计归约、容量、种子与哈希；这不代表真机质量、公平性或近期系统对比已经通过。
