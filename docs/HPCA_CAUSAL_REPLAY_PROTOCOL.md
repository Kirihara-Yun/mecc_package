# D1 因果机制回放协议（2026-10-27，首次运行前固定）

目的：替换 PPT 中手填的有利曲线，检验“初始先验、跨层保留、请求次序”三个因素在一个明确抽象中的作用。该实验不是 A100 性能实验，不验证真实 MoE 路由具有相同局部性，也不替现有 CUDA 实现背书。

固定配置：16 个等大小只读对象，HBM 2 槽、CPU 4 槽，总容量小于对象集合；不含镜像、预取和时间模型。8 个种子 `[3,11,23,37,47,61,79,97]` 全部保留。独立的训练 RNG 产生 1024 个 Zipf(1.2) 请求，估计初始排序；测试 RNG 产生 1024 个请求。测试频次不参与画像。无画像初态使用配对的随机排名；所有策略初始化都读取相同数量的对象。

实验臂为 `random_static`、`profile_static`、`random_joint`、`profile_joint`：仅改变初始排序和 CPU 保留规则，HBM 使用同一 LRU。静态 CPU 可以与 HBM 包含同一对象，CPU 实际对象数仍不超过 4；联合 CPU 与 HBM 排他驻留并按 LRU 升降级。联合方案需付出的 D2H 对象数单独记录，不假设搬运免费。记录的是需求到来时的来源层级，和未来预取无关。

工作负载预先固定为四项，均不得按结果筛选：

- stationary：每 32 请求抽取一个 4 对象局部工作集，按 Zipf 偏好选择对象，再在工作集中均匀访问；两个阶段使用相同分布。这是人为局部性压力测试，不是模型实测。
- drift：前 512 请求同 stationary，后 512 请求把 Zipf 偏好整体循环移动 8 位。
- phase_shuffled：只打乱 drift 每个阶段内部的访问次序；每个阶段的逐对象总次数完全相同，阶段切换保留。
- uniform：所有对象等概率独立请求，作为低偏斜且无时间局部性的负对照。

预先指定的图：

1. 相同联合在线规则下，画像/随机初态在前 16/32/64/128/256 次请求的累计 SSD demand misses；只回答初态效应，不宣称完整服务收益。画像采集、编译和预热成本还须在 L2 计入。
2. 相同画像下，静态/联合 CPU 在原顺序/阶段内乱序条件下的 SSD misses/千请求；只打乱次序控制边际频率，检验复用结构是否重要。
3. drift 下完整 2×2 的逐窗 SSD misses/千请求，保留无画像联合 LRU 这一强机制对照，检验画像在初期与失配后的价值是否不同。
4. uniform 负对照及迁移对象数，保留退化或无优势，不只展示“完整方案最好”的情形。

图中误差棒为 8 个合成种子的均值±标准差，表示合成请求变异，不是 A100 重复运行方差。不得把回放用时转换成 tok/s，也不得借用 5090 读延迟推算 A100 加速。

命令：`python mecc_package/scripts/motivation_causal_replay.py`。输出采用 B 类 `workloads` 结构，保存在 `results/raw/motivation_causal_replay_20261027.json`，包含平台、时间、脚本 SHA、训练/测试 trace 哈希、完整测试序列、逐 seed 原值、迁移计数与容量断言。另存 `results/logs/20261027_D1_causal_replay.md` 记录结果，不覆盖历史文件。

## 二轮审查后的 v2 协议修正（保留 v1）

首次运行的 v1 原值保留。审查指出训练 iid Zipf 与测试局部工作集生成器不同，v2 改为同局部工作集生成器的独立训练序列，避免把名义 stationary 的训练失配当作初态实验。种子、容量、测试生成规则、长度和全部工作负载不变；这属于明确披露的协议修订，不选择有利结果。

v2 增加 `random_independent` 与 `profile_independent` 两臂：HBM、CPU 各自动态 LRU，CPU 允许在 HBM 命中对象的副本存在，并计入同一个 4 槽 CPU cap。这允许同时观察静态/动态与跨层副本覆盖的影响；不声称 static→joint 只隔离了动态性。新增逐时平均唯一驻留数和跨层重复数，`hidden_cpu_mirrors=false` 只表示没有预算外镜像，并不禁止已计费的重复对象。

新增容量为 H+C 的普通全局 LRU 参考实现，对每个联合臂逐请求断言 SSD miss 完全一致。因此这份 D1 实验不把联合 LRU 本身包装成新替换算法。v2 输出 `motivation_causal_replay_20261027_v2.json`，本轮 PPT 只用 v2；v1 不混入图表。

制图时的单条序列 CDF/热图统一取种子列表首项 3，按固定索引展示，不根据图形效果挑选。均值/标准差图使用全部 8 个种子；单条热图不代表 8 个种子的平均状态。
