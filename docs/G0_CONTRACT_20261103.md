## 6. 决策点（2026-11-04 已确认）

1. **介质口径**：✅ **内部实验按旋转块设备口径推进**。论文正文/图注不得写本机是 SSD/NVMe；在取得控制器后物理盘证据前，写「本地 RAID 块设备（操作系统报告旋转介质）」。保留现有数据，不迁移设备。
2. **"SSD-native adapter" 映射**：✅ **用 `ours_io`**（`e2e/policy_plugin.py:OursIOPolicy`，OURS + ThreadPool 并行 SSD I/O）。补跑 `ours_io` 进 fig04。注：`ours_io` 是 ours 的 I/O 变体，**非第三方 SSD-LLaMA**，图注须写明身份。
3. **8x22B / 多卡横轴**：⚠️ **用户决策：先用理想值填充**（`paper/dac2027/ideal_assumptions.json`）。**诚实约束（不可越）**：理想值为 HYPOTHETICAL DESIGN TARGETS，**只能用于「情景示意」版并明确标注「理想目标 / 非实测」**，不得与实测值混成"实验结果"图；正式版多卡/8x22B 柱标 `ideal` 或 `blocked`，实测横轴仍用"任务/预算/长度"。详见 `PAPER_WRITING.md` 三诚实门禁。
4. **正式预算**：✅ **先物理峰值验证再冻结**。用 X7 计量（`--trace_memory` / resource_trace）测 50/40GB 峰值；若 HBM=50 不安全（fiddler 峰值已 78.6/80GB），全策略一起降预算重冻结并重跑。
